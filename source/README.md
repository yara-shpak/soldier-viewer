# Вхідні файли

Не зберігаються в репозиторії. Покладіть сюди перед запуском пайплайна (`python pipeline/build.py`):

| Файл | Що це |
|---|---|
| `soldier.mp4` | відео обертання солдата (960×960 або більше) |
| `zones.svg` | маски інтерактивних зон, координати = кадр 0 відео |
| `hangar_360.png` | еквіректангулярна панорама ангару |
| `hangar_360_upscaled.png` | опційно: AI-апскейл панорами ×2–×4 → `pano_8192.jpg` |

Готові веб-ассети вже лежать у `public/assets/`, тож для збірки й деплою (`npm run build`) пайплайн запускати не обов'язково.
